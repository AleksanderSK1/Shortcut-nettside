Oversikt

Dette er dokumentasjonssiden for IT-løsningen jeg setter opp for den fiktive bedriften Shortcut IT Support. Siden er laget for å vise hva som er gjort i prosjektet, hvordan løsningen er bygget opp, og hvilke valg som er tatt underveis. Løsningen består av Windows Server 2022, Active Directory, DNS, DHCP, IIS, SSH og en intern nettside som hostes på serveren.

Dokumentasjon

Så langt i prosjektet har jeg satt opp en Windows Server 2022 i en virtuell maskin. Serveren har fått navnet SRV-SHORTCUT01 og er satt opp som domenekontroller for domenet shortcut.local. Active Directory brukes for å administrere brukere og grupper i nettverket. DNS er konfigurert på Windows Server slik at interne navn kan brukes i stedet for IP-adresser. Jeg har laget en DNS-record som gjør at nettsiden kan åpnes med support.shortcut.local. Dette gjør løsningen mer realistisk, fordi ansatte eller administratorer slipper å huske IP-adressen til serveren. IIS er installert og brukes til å hoste denne nettsiden. Nettsidefilene ligger på serveren og oppdateres via Git. Jeg utvikler nettsiden på MacBook, sender endringer til GitHub og henter dem ned på Windows Server. Dette gjør arbeidsflyten mer ryddig og viser hvordan utvikling og drift kan henge sammen.

IP-plan

IP-planen er laget for en liten bedrift med omtrent 50 ansatte. Jeg bruker nettverket 192.168.20.0/24, som gir nok adresser til servere, klienter, skrivere, administrasjon og fremtidig utvidelse. Serveren har statisk IP-adresse fordi den kjører sentrale tjenester som Active Directory, DNS, DHCP og IIS.

DHCP-området fra 192.168.20.100 til 192.168.20.180 gir 81 mulige klientadresser. Det passer godt for en bedrift med cirka 50 ansatte, fordi det gir nok adresser til alle ansatte samtidig som det finnes ledig kapasitet. Servere, skrivere og administrasjonsmaskiner ligger utenfor DHCP-området fordi disse bør ha faste adresser.

Feilsøking

Denne delen viser enkel brukerstøtte med JavaScript. Den kan brukes til å forklare vanlige problemer i løsningen og hvilke kontroller som bør gjøres først.
