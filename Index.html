Shortcut IT Support

Velkommen til den interne IT-portalen for Shortcut IT Support.

Her kan ansatte finne informasjon om serveren, nettverket og brukerstøtte.

Dokumentasjon

Prosjekt

Dette prosjektet handler om å sette opp en intern IT-løsning for bedriften Shortcut IT Support.

Løsningen består av Windows Server, Active Directory, DNS, DHCP, IIS og en intern nettside.

Server

Servernavnet er SRV-SHORTCUT01.

Domenet heter shortcut.local.

Serveren har IP-adressen 192.168.20.10.

Brukerstøtte

Denne nettsiden brukes som dokumentasjon for ansatte og IT-ansvarlige.

Her kan ansatte finne informasjon om hvordan systemet er satt opp og hvor de kan få hjelp.
