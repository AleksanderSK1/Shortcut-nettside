Brukerstøtte og dokumentasjon

Dette er den interne dokumentasjonen for Shortcut IT Support. Løsningen er satt opp med Windows Server 2022. Serveren brukes til sentrale tjenester i nettverket, blant annet Active Directory, DNS, DHCP og IIS. Servernavnet er SRV-SHORTCUT01. Domenet heter shortcut.local. Serveren har statisk IP-adresse 192.168.20.10. DNS er satt opp slik at ansatte kan åpne supportsiden med support.shortcut.local i stedet for å skrive IP-adressen manuelt. IIS brukes til å hoste denne nettsiden. Nettsiden fungerer som en intern supportportal der ansatte kan finne informasjon om IT-systemet. SSH er satt opp slik at serveren kan administreres fra MacBook. Dette gjør det mulig å oppdatere nettsiden mer effektivt uten å kopiere filer manuelt. På eksamensdagen kan denne siden oppdateres underveis med det som blir gjort i serveroppsettet.
